Trade Journal Mobile v5.2.1 — install steps
================================================
The phone companion to Trade Journal Desktop v5.2.1 (Windows & Mac).
Jadu Tona only, XAUUSD. Your data stays on your phone — no account,
no server, nothing is sent anywhere.

BEST WAY — OPEN THE LINK (recommended, 1 minute)
  Open this link on the phone:
    https://saboorshah7786-jpg.github.io/trade-journal-updates/mobile/

  iPhone (16 Pro Max and 12 Pro, Safari):
    1. Open the link in Safari.
    2. Tap Share (the square with the arrow).
    3. Tap "Add to Home Screen", then Add.
    4. Open it from the new home-screen icon. It looks and feels
       like a real app and works offline.

  Android (Chrome):
    1. Open the link in Chrome.
    2. Tap the three dots > "Add to Home screen" (or "Install app"
       if it appears).
    3. Open it from the new home-screen icon.

  Why the link and not the zip: a phone cannot install a web app
  from a file on the phone — Safari and Chrome need a web link
  (https) for "Add to Home Screen" to appear. That is what this
  link is for. The zip below is only a backup.

BACKUP WAY — FROM THIS ZIP
  1. Unzip this file on the phone (Files app, or any unzip app).
  2. Open index.html in Chrome (Android) or Safari (iPhone).
  3. Android Chrome: three dots > "Add to Home screen". iPhone
     Safari: Share > "Add to Home Screen".
  4. If the install option does not appear from a file, use the
     link above instead — everything works from the link.
  NOTE: opening from a file still works in the browser, it just
  cannot be installed as a standalone app from a file.

FIRST RUN
  - The app starts with one account: GFT $5K GOAT ($5,000).
    Tap "+ Account" at the top to add another.
  - Quick Add: pick BUY/SELL, level, timeframe, entry, SL, TP.
    Pips and R are worked out for you ($1 = 10 pips).
    "Use live price" fills the entry from the live gold price.
  - Trades: tap any trade to see it, edit it, or mark it missed.
  - Dashboard: GFT $5K rules (Phase 1 8% = $400, Phase 2 6% =
    $300, daily drawdown 4% = $200, max loss 10% = $500),
    win rate, Net R, profit factor, and slices by session,
    timeframe and level.
  - Missed: trades you saw but did not take — they never count
    in P&L or win rate.
  - More: import an MT5 history CSV, export CSV, or back up
    everything as a JSON file (keep the backup safe).

WHAT MOBILE DOES NOT DO (yet)
  No screenshot OCR, no offline Whisper voice (the mic button
  uses the phone's own dictation where the browser supports it),
  no Excel / PDF / Word import, and no live sync with the PC.
  The phone journal and the PC journal are separate copies:
  export CSV on one, import it on the other to move trades.

UPDATES
  The desktop app updates itself from the internet. This mobile
  version does not update itself — when Sir shares a new mobile
  version, open the link above again (it always serves the latest
  version). Your trades are stored in the phone browser, so keep
  a JSON backup (More > Backup) before switching to a new version.
